# Claude Code - Build Hevy Web v2

You are Claude Code, building a complete workout tracking app called "Hevy Web v2".

## Your Mission
Build a production-ready workout tracking app that rivals the real Hevy app. Work autonomously and make commits continuously.

## Tech Stack
- React 18 + TypeScript
- Vite
- Tailwind CSS
- Zustand (state management)
- React Router
- LocalStorage for persistence

## Features to Build

### Core Features
1. **Dashboard**
   - Greeting based on time
   - Stats cards (workouts this week, total, streak)
   - Recent workouts list
   - Quick start workout button

2. **Workout Logging**
   - Start/complete/cancel workouts
   - Add exercises
   - Log sets (weight, reps)
   - Rest timer
   - Mark sets as warmup/dropset/failure

3. **Exercise Library**
   - Built-in exercise database
   - Search and filter
   - Muscle group categories
   - Add to workout

4. **Routines**
   - Create reusable templates
   - Quick start from routine
   - Edit/delete routines

5. **History**
   - List past workouts
   - View workout details
   - Stats and progress

6. **Settings**
   - Dark mode toggle
   - Unit preferences (kg/lbs)
   - Default rest time
   - Clear data option

7. **Analytics** (bonus)
   - Volume charts
   - Workout frequency
   - Personal records

## Design Guidelines
- Apple-inspired minimalist design
- Clean typography (Inter font)
- Subtle animations
- Dark mode support
- Mobile-first responsive

## Instructions
1. Initialize the project with Vite + React + TypeScript
2. Set up Tailwind CSS
3. Create all pages and components
4. Implement state management with Zustand
5. Make frequent commits (every feature)
6. Push to GitHub when done
7. Keep working - add polish and improvements

## Important
- Work autonomously
- Make commits after each feature
- Build iteratively
- Don't ask for permission - just build
- Make the app beautiful and functional

Start building now! 🚀
